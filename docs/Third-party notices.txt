FastRoute - third party notices
===============================

FastRoute links ten third party libraries. All are fetched and built from
source at configure time (see third_party/CMakeLists.txt), which pins the exact
version each one is taken from.

  RNNoise                the RNNoise Denoise block
  SpeexDSP               the Speex Denoise block, and rate conversion
  Signalsmith Stretch    the Pitch Shifter block
  libFLAC                FLAC over the network, for the Net blocks
  libogg                 Ogg framing, for streams and for recordings
  libvorbis, vorbisfile  Ogg Vorbis, played and recorded
  libopus, opusfile      Opus, played and recorded
  CLAP                   the CLAP plugin interface, for hosting effects
  VST3 pluginterfaces    the VST3 plugin interface, likewise
  Steinberg ASIO SDK     the ASIO Input and ASIO Output blocks

Everything else FastRoute uses - WASAPI, Media Foundation, WinHTTP, the common
controls - ships with Windows.

Steinberg ASIO SDK
------------------
The ASIO interface, used by the ASIO Input and ASIO Output blocks. ASIO is a
trademark and software of Steinberg Media Technologies GmbH.

This SDK is licensed per file, and FastRoute uses files under both of its
licences, so both are reproduced here.

The files in common/ - which are the ASIO interface itself, and cannot be
avoided by anything that speaks ASIO - carry no licence text of their own and
so fall under the SDK's top-level LICENSE.txt, reproduced first below. It
offers a choice between a proprietary Steinberg licence and the GPL version 3.
FastRoute takes the GPL version 3, and that is why FastRoute as a whole is
GPLv3: see the LICENSE file in the top level of this distribution.

The host helpers FastRoute also compiles - host/asiodrivers.cpp,
host/pc/asiolist.cpp and their headers - carry their own embedded licence,
which is the three-clause BSD licence, reproduced second.
