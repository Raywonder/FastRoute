Welcome to FastRoute! FastRoute is designed to be an Audio Hijack type of application for the Windows platform. It is built specifically for accessibility, so it is completely usable by screen reader users.
When you first launch FastRoute, you will land in the sessions list. FastRoute categorizes all of your different routing situations as sessions. For instance, you could have a session to record from your web browser, you could have a session to route your microphone to a virtual audio cable, you could have sessions to route individual apps or your system audio to a virtual audio cable with effects, etc, and run them all independantly of each other.
This sessions list will be empty by default, so you'll press control N to create a new one. You'll be asked for the session title. Press enter, and you're in the session window.
The session window contains the blocks library, which is a standard tree view containing things like input blocks, effects blocks, and output blocks.
Input blocks are things like input devices, application capture devices, and system audio capture and internet radio streams.
An application block can also be pointed at whatever application is in front instead of at one you name, either deciding once when the block starts or following the foreground as it changes. The best way to use that is to hide FastRoute to the tray and start the session from a global hotkey, so FastRoute itself is never the application in front.
Effects blocks are blocks you can use to enhance your audio. This may be an EQ, a normalizer, a pitch shifter, a denoiser, a compressor or limiter, or a stereo channels manipulator.
As well as the ten band EQ there's a four band parametric one, where each band has its own shape, frequency, gain and Q, so you can go after one specific frequency instead of a whole octave. There is also a noise gate for the hiss between the words, and you can use your own CLAP and VST3 plugins: add the folders they live in under settings, press scan, and they turn up in the blocks library under external effects. Their parameters are all listed as text so you can read and set them with the keyboard, and there's a button to open the plugin's own window if you want it.
There's also a pitch shifter, which moves the pitch up or down without changing the speed. Set it in whole semitones and in cents for anything in between. It has to work a window of sound at a time, so it delays the audio by that window, and the quality setting is really a choice of how much delay you want to spend: best is 120 ms, balanced is 60 and low delay is 30. Set to no shift at all it costs nothing and delays nothing. It doesn't keep formants, so a voice shifted up goes up whole, chipmunk and all.
Output blocks are blocks where you want to send your audio. This may be a recording file, an output device, or even a device over the network, an internet live stream or similar.
You can also send audio to another computer and receive it there, with the net send and net receive blocks. On the same network you don't need to know any addresses: a sender announces itself, so the receive block just lists what it can hear and you pick one. For a machine further away, start the net send block first and then type that machine's name or address into a net receive block on the other one - the receiving end asks for the audio, so you don't have to open anything up on that side. It also speaks VBAN, so it works with VoiceMeeter and with the VBAN apps on phones and tablets. You can send plain PCM, or FLAC if you want it lossless but smaller, or Opus if you're going over wifi and want it small. The buffer setting is how much unevenness the network is allowed before you can hear it; 60 ms is fine on a cable, wifi usually wants more.
To stream live, add a Stream Out block. Pick the server type: RTMP for AAA Streamer and most streaming platforms, Icecast 2, or Shoutcast 1 or 2. For AAA Streamer, press the AAA Streamer button in the block's dialog and then Sign in: your browser opens the AAA Streamer page, you approve FastRoute there, and then you pick one of your streams from the list and press Use this stream, which fills in the address and stream key for you. You never type your AAA Streamer password into FastRoute. For Icecast, type the server and port, such as stream.example.com:8000, the mount point, the user (leave it blank for source) and the source password. Icecast takes AAC, MP3, Ogg Opus or Ogg Vorbis; Shoutcast takes AAC or MP3; RTMP is always AAC. MP3 only shows up if Windows has an MP3 encoder. The station name, genre, description, website and public listing go to Icecast and Shoutcast, and the now playing title is sent again every time you change it and press alt A, without dropping the stream. The stream key or password is saved encrypted for your Windows user, so if you copy FastRoute to another computer you'll need to type it again. When the session runs, NVDA or JAWS will say when the stream connects, goes live, loses the connection and reconnects, and the times field at the bottom of the session window says how much has been sent. If the connection drops it keeps trying on its own, waiting a little longer each time, up to a minute. A handy layout for sending Reaper or another program to the stream while you talk on your microphone somewhere else: an application block for Reaper, or an ASIO input block on the ReaRoute ASIO driver with ReaRoute 1 and 2, then the Stream Out block, then your microphone, then an output device block, so the stream only gets Reaper and you hear both. With ReaRoute, set Reaper and your Windows default output to the same sample rate, 48000 is best, or the session won't start and will tell you which rate to set. FastRoute can only use one ASIO driver at a time, so while ReaRoute is in use, use your audio interface's normal Windows device for your microphone rather than its ASIO driver. Sending straight into a VoiceLink room with a VoiceLink sign-in isn't there yet, because VoiceLink doesn't have a way for programs to do that yet.

These blocks can be placed in whatever order you want. For instance, if you want the audio to be sent through an EQ to your audio device, but not when recording, you could place your input blocks, then your recording block to capture the raw signal, then your EQ blocks and then your output device block to capture the equalized audio only to your output device.
Use control up/down arrow to move blocks. If a session is running, you can hear the new effect immediately.
Press enter on a block in your blocks list to open it's perametors dialog. Use space to toggle that particular block on or off.
In a parameters dialog, up and page up raise a slider and down and page down lower it, and each slider reads out what it's actually set to, like 250 Hz or hard left or -6 dB, rather than a percentage of how far along it is. Alt A applies your changes without closing the dialog, so you can hear them and keep adjusting.
Use shift F10/applications on a block to access other options, such as setting a global hotkey to toggle that block on or off.
To run a session, use control R.
Finally, you can use alt up/down arrows to adjust the block you're focused on's volume.
Press F2 on a block to give it a name of your own, which is handy when you have two of the same kind in one session.
Both the session window and the sessions list have a read only field at the bottom telling you what's running and for how long, and if you're recording, how long for and how big the file is so far.
FastRoute keeps its settings next to the program itself, so you can put the whole folder on a memory stick and take your sessions with you.
Outside the session window, in the sessions list, you can use shift F10/applications key to modify some aspects of the session, like if this session should auto run on app startup or not. Additionally, you can use control R in the sessions window to run the currently focused session.
Press control comma to open the settings.
Settings is also where you say how often FastRoute looks for a new version of itself - never, when it starts, hourly or daily - and whether it installs one without asking you first. A check that can't reach the server says nothing and tries again quietly a few minutes later. It writes a line to the error log, under help, and that's all.
The last box in settings is "Send update results and error reports (no personal content)", and it's on. It means that when an update installs, fails, or doesn't reopen FastRoute afterwards, FastRoute tells our server so we can fix it, and once a day it says which version you're running so we know how many people are on which build. A report has a random install number that isn't tied to you or to any account, the FastRoute version, your Windows version and a short description of what went wrong. It never has your sessions, file names, recordings, devices, stream keys, passwords or user name in it. If you'd rather it didn't, turn the box off; anything waiting to be sent is thrown away.
The same box covers two more things. If FastRoute ever stops unexpectedly, then the next time you start it, it tells us what it stopped on - which error, and where in the program as a number. Nothing about what you were doing, and nothing you have to do: Windows behaves exactly as it does now. And a handful of faults that are FastRoute's own doing rather than your machine's are reported as they happen, which is the main window failing to open, a scheduled event pointing at a session that's been deleted, and an edit to a running session that stops it. Everything else that reaches the error log stays there and goes no further, because most of it isn't a bug - a session whose program isn't open yet, an unplugged interface, a stream host that's down, a hotkey another program has already taken.
Help, Send Diagnostic Logs is for when something's wrong that no single report explains. It shows you the exact report it would send - the error log, with your user folder name and the sign-in part of any address taken out of it - and a box to say what you were doing when it went wrong, which is optional. Nothing is sent until you press Send. When it's gone, FastRoute says a reference like "fastroute 42"; quote that if you write to us about it, and Copy Reference puts it on the clipboard for you. This button is the only thing that sends a log, and it works whether or not the settings box is on, because that box is about what FastRoute sends on its own.
You may want to hide FastRoute into your system tray. You can do this. Press control H in the main window to hide. The default global hotkey is control alt R.
